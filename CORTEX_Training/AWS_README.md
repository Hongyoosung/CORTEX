# AWS EC2 Distributed Training Setup

This directory contains scripts and configurations for running SBDAPM training on AWS EC2.

## Quick Start

**Prerequisites:** AWS account, AWS CLI configured, UE5 packaged for Linux

```bash
source aws_config.env
```

```bash

```

### Scripts
- **`aws_setup.sh`** - Automated AWS infrastructure setup
  - Creates S3 bucket, VPC, security groups, IAM roles
  - Outputs: `aws_config.env` with all IDs

- **`worker_setup.sh`** - Worker instance setup script
  - Run on base EC2 instance to install dependencies
  - Downloads game build from S3
  - Configures Schola and systemd service

- **`train_rllib.py`** - Training script (AWS mode supported)
  - Automatically detects `WORKER_IPS` env variable
  - Switches between local and distributed mode

### Configuration
- **`Dockerfile`** - Head node training container
- **`requirements.txt`** - Python dependencies
- **`aws_config.env`** - Generated by `aws_setup.sh` (not in git)

## Training Modes

### Local Mode (Default)
```bash
python train_rllib.py --iterations 100
# Uses localhost with port offsets (50051, 50052, ...)
```

### AWS Distributed Mode
```bash
export WORKER_IPS="34.XX.XX.XX 54.XX.XX.XX 18.XX.XX.XX"
export NUM_WORKERS=3
python train_rllib.py --iterations 1000
# Connects each worker to specific IP
```

## Cost Optimization

### 1. Use Spot Instances (70% savings)
```bash
# Already included in scripts
--instance-market-options 'MarketType=spot,SpotOptions={MaxPrice=0.30}'
```

### 2. Choose Cheapest Region
- us-east-1: $0.158/hr spot (recommended)
- us-west-2: $0.165/hr spot
- Check current prices: https://instances.vantage.sh/

### 3. Start Small
Test with 2 workers (2 hours, ~$0.63) before scaling to 8 workers

### 4. Monitor Costs
```bash
aws ce get-cost-and-usage \
    --time-period Start=$(date +%Y-%m-01),End=$(date +%Y-%m-%d) \
    --granularity MONTHLY \
    --metrics BlendedCost
```

## Troubleshooting

### Worker Schola not starting
```bash
ssh ubuntu@WORKER_IP
sudo systemctl status sbdapm-worker
tail -100 /home/ubuntu/ue_worker.log
```

### Connection timeout
```bash
# Check security group
aws ec2 describe-security-groups --group-ids $SG_WORKER

# Test connection
telnet WORKER_IP 50051
```

### Training slow
```bash
# Check worker CPU
ssh ubuntu@WORKER_IP "top -bn1 | head -20"

# Expected: 60-90% CPU usage
# If 100%: upgrade to g4dn.2xlarge
```

## Cleanup

### Stop Training (keep infrastructure)
```bash
# Terminate instances
aws ec2 terminate-instances --instance-ids $WORKER_INSTANCES $HEAD_INSTANCE
```

### Delete Everything
```bash
# Delete S3 bucket
aws s3 rm s3://$BUCKET_NAME --recursive
aws s3 rb s3://$BUCKET_NAME

# Deregister AMI
aws ec2 deregister-image --image-id $WORKER_AMI

# Delete security groups
aws ec2 delete-security-group --group-id $SG_WORKER
aws ec2 delete-security-group --group-id $SG_HEAD

# Delete IAM role
aws iam remove-role-from-instance-profile \
    --instance-profile-name SBDAPM-Worker-Profile \
    --role-name SBDAPM-Worker-Role
aws iam delete-instance-profile --instance-profile-name SBDAPM-Worker-Profile
aws iam detach-role-policy --role-name SBDAPM-Worker-Role \
    --policy-arn arn:aws:iam::aws:policy/AmazonS3ReadOnlyAccess
aws iam detach-role-policy --role-name SBDAPM-Worker-Role \
    --policy-arn arn:aws:iam::aws:policy/AmazonSSMManagedInstanceCore
aws iam delete-role --role-name SBDAPM-Worker-Role
```

```bash

BUCKET_NAME=sbdapm-training-123456789012
VPC_ID=vpc-xxxxxxxxx
SG_WORKER=sg-xxxxxxxxx
SG_HEAD=sg-xxxxxxxxx
KEY_PAIR_NAME=your-key
WORKER_AMI=ami-xxxxxxxxx  # Set after AMI creation
```

Load with: `source aws_config.env`
