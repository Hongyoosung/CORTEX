# CORTEX v10.0: Hierarchical Temporal MCTS-RL with Adaptive Options

**Engine:** UE5.6 | **Language:** C++17 | **Platform:** Windows | **Version:** v10.0  
**Status:** 🎯 Design Phase | **Date:** 2026-02-05

***

## Executive Summary

CORTEX v10.0 introduces **Option-based Hierarchical Temporal Planning**, integrating MCTS for high-level option selection with RL for continuous low-level execution in real-time multi-agent combat. This architecture addresses the fundamental question: *"When should agents replan their strategies?"* through learned termination conditions rather than fixed time intervals.

**Core Innovation:**
```
v9.0:  MCTS (fixed 30s) → Strategy → RL → Tactical Execution
v10.0: MCTS → [Option: Strategy + Duration + Termination] → RL → Adaptive Replanning
```

**Key Contributions:**
- **Temporal Options Framework**: MCTS plans multi-step option sequences with learned termination
- **Learned Termination**: RL decides "when to replan" based on battlefield state
- **Temporal UCB1**: Credit assignment algorithm for time-extended actions
- **Academic Novelty**: First integration of MCTS + Options + RL in real-time multi-agent continuous control

## 1. Motivation & Problem Statement

### 1.1 Limitations of Current Approaches

**Fixed-Interval Replanning (v9.0):**
- MCTS runs every 30s regardless of battlefield state [ppl-ai-file-upload.s3.amazonaws](https://ppl-ai-file-upload.s3.amazonaws.com/web/direct-files/attachments/72742881/a3be87d3-2085-4a98-8cb8-fe15028a06f0/CLAUDE.md)
- Wastes computation when situation is stable
- Reacts slowly when urgent changes occur (enemy rush at t=15s → waits until t=30s)

**Brute Force Strategy Selection:**
- 4 agents × 2 strategies × 5 objectives = 40 combinations → solvable by exhaustive search
- **MCTS becomes unnecessary** for single-step decisions
- No temporal reasoning about future state transitions

### 1.2 Research Question

> *How can we leverage MCTS for temporal planning in dynamic environments where immediate action spaces are small, but multi-step sequential decisions create exponential complexity?*

### 1.3 Solution Approach

**Options Framework Integration:**
- MCTS selects **temporally extended actions (options)** rather than instantaneous strategies
- Each option = {strategy, target, duration, termination condition}
- Action space: 8 options × 3 durations × 4 agents = 96 combinations (single-step)
- Sequential space: 96^3 = 884,736 combinations (3-step lookahead) → **MCTS justified**

## 2. Architectural Overview

### 2.1 Three-Layer Hierarchy (v10.0)

```
┌─────────────────────────────────────────────────────────────────┐
│ Layer 1: Temporal MCTS (Option Planning)                        │
│ ─────────────────────────────────────────────────────────────── │
│ Frequency: Event-driven (on option termination)                 │
│ Latency: 10-20ms                                                │
│ Output: Option sequence [Opt1: 0-15s, Opt2: 15-40s, Opt3: 40-60s] │
│                                                                  │
│ Algorithm: Temporal UCB1 with Progressive Widening              │
│ ├─ Selection: Choose highest temporal-UCB1 child                │
│ ├─ Expansion: Add new option branches (duration variants)       │
│ ├─ Simulation: Rollout option sequence to horizon               │
│ └─ Backpropagation: Temporal credit assignment with decay       │
└─────────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────────┐
│ Layer 2: RL Policy (Option Execution + Termination)             │
│ ─────────────────────────────────────────────────────────────── │
│ Frequency: 2-5 Hz                                               │
│ Latency: 2-4ms                                                  │
│                                                                  │
│ Input: Observation (56 features) + Current Option Context       │
│ ├─ Base Features: 52 (agent, combat, environment, objectives)   │
│ ├─ Option Context: 4 (strategy one-hot, time elapsed, target)   │
│ └─ Total: 56 features                                           │
│                                                                  │
│ Output: Tactical Parameters + Termination Signal                │
│ ├─ Continuous Actions: [Aggression, Cover, Spread, Risk]        │
│ └─ Termination Logit: P(should terminate option now)            │
│                                                                  │
│ Reward Structure:                                               │
│ ├─ Task Reward: Strategy-specific (v9.0 maintained)             │
│ ├─ Termination Reward: Value(new option) - Value(continue)      │
│ └─ Option Completion Bonus: +reward if terminated at right time │
└─────────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────────┐
│ Layer 3: EQS + Combat System (Low-Level Execution)              │
│ ─────────────────────────────────────────────────────────────── │
│ Frequency: 2-5 Hz (EQS), 60 Hz (combat)                         │
│ Logic: Environmental queries with RL-modulated weights          │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 System Flow (Real-Time Execution)

```
[t=0s] Combat Start
├─ Trigger: Team spawned
└─ MCTS Planning (15ms)
   ├─ Root: Current state (all agents at spawn)
   ├─ Simulate 3-step sequences (depth=3, horizon=60s)
   │  Example sequence:
   │  ├─ [0-15s]: Opt1 (Agent0,1: Attack→PointA, Agent2,3: Defend→Base)
   │  ├─ [15-35s]: Opt2 (If PointA captured: All Attack→PointB)
   │  └─ [35-60s]: Opt3 (If PointB captured: Defend→PointB)
   ├─ Temporal UCB1 Selection
   └─ Output: Execute Opt1 for all agents

[t=0-15s] Option Execution Phase
├─ RL Policy (2-5 Hz):
│  ├─ Execute Attack strategy (Agent0,1)
│  │  └─ Tactical params: Aggression=0.85, Cover=0.3
│  └─ Execute Defend strategy (Agent2,3)
│     └─ Tactical params: Aggression=0.2, Cover=0.8
│
├─ Termination Check (every 1s):
│  ├─ Time-based: elapsed > minDuration (10s) ✓
│  ├─ State-based: PointA captured? ✓ (at t=13s)
│  └─ Learned: RL termination_logit > threshold? ✓
│
└─ Early Termination at t=13s → Trigger MCTS replanning

[t=13s] Replanning Event
├─ MCTS Update:
│  ├─ Backpropagate Opt1 result (PointA captured in 13s → +reward)
│  ├─ Update UCB1 statistics
│  └─ New root: Current state (PointA under control)
├─ MCTS Planning (12ms):
│  └─ Select Opt2: All Attack→PointB (exploit early success)
└─ Resume execution with new option

[t=13-40s] Option 2 Execution
├─ All agents execute Attack→PointB
├─ Termination check: Enemies counterattack, HP drops
├─ Learned termination triggers at t=28s (HP < 30%)
└─ MCTS replans → Opt3: Tactical Retreat→Base

[t=28-60s] Option 3 Execution
└─ Complete combat...
```

### 3.3 Temporal UCB1 Algorithm

```cpp
// File: AI/MCTS/TemporalUCB1.cpp

/**
 * Temporal-aware Upper Confidence Bound
 * Balances exploitation/exploration with temporal relevance
 */
float FTemporalMCTSNode::CalculateTemporalUCB(float currentTime, float C) {
    if (VisitCount == 0) {
        return FLT_MAX;  // Unvisited nodes have infinite priority
    }
    
    // Standard UCB1 components
    float exploitationTerm = TotalReward / VisitCount;
    float explorationTerm = C * sqrt(log(Parent->VisitCount) / VisitCount);
    
    // ===== Temporal Relevance Weight (v10.0 innovation) =====
    
    float timeDelta = abs(ActivationTime - currentTime);
    float temporalDiscount = exp(-0.1f * timeDelta);
    // Nodes far in future/past get discounted
    // λ=0.1: Half-weight at ~7 seconds
    
    // Urgency bonus for near-term decisions
    float urgencyBonus = 0.0f;
    if (timeDelta < 5.0f) {
        urgencyBonus = 0.5f * (1.0f - timeDelta / 5.0f);
    }
    
    // ===== Final UCB1 =====
    
    float ucb1 = exploitationTerm + explorationTerm * temporalDiscount + urgencyBonus;
    
    return ucb1;
}

/**
 * MCTS Selection Phase with Temporal Pruning
 */
FTemporalMCTSNode* SelectBestChild(FTemporalMCTSNode* node, float currentTime) {
    FTemporalMCTSNode* bestChild = nullptr;
    float bestUCB = -FLT_MAX;
    
    for (FTemporalMCTSNode* child : node->Children) {
        // Skip temporally irrelevant nodes (optimization)
        if (!child->IsTemporallyRelevant(currentTime, 30.0f)) {
            continue;
        }
        
        float ucb = child->CalculateTemporalUCB(currentTime);
        if (ucb > bestUCB) {
            bestUCB = ucb;
            bestChild = child;
        }
    }
    
    return bestChild;
}
```

```cpp
void UOptionExecutor::ExecuteOption(float deltaTime) {
    if (!CurrentOption) return;
    
    CurrentOption->ElapsedTime += deltaTime;
    
    // Get observation
    FObservation obs = ObservationProvider->GetObservation(GetOwner());
    
    // Query RL policy
    FRLOutput rlOutput = QueryRLPolicy(obs);
    
    // Apply tactical parameters to behavior system
    ApplyTacticalParameters(rlOutput.TacticalParameters);
    
    // Check termination
    bool shouldTerminate = CheckTermination(obs, rlOutput.TerminationLogit);
    
    if (shouldTerminate) {
        ETerminationReason reason = DetermineTerminationReason(obs, rlOutput);
        OnOptionTerminated(reason);
        
        // Trigger MCTS replanning
        GetTeamLeader()->RequestReplanning(reason);
    }
}

bool UOptionExecutor::CheckTermination(const FObservation& obs, float rlLogit) {
    const auto& term = CurrentOption->Termination;
    float elapsed = CurrentOption->ElapsedTime;
    
    // Minimum duration not met
    if (elapsed < term.MinDuration) {
        return false;
    }
    
    // Maximum duration exceeded (hard cutoff)
    if (elapsed > term.MaxDuration) {
        return true;
    }
    
    // State-based conditions
    if (term.bTerminateOnObjectiveReached && obs.ObjectiveDistance < 0.05f) {
        return true;
    }
    
    if (term.bTerminateOnHealthCritical && obs.AgentHealth < 0.2f) {
        return true;
    }
    
    if (term.bTerminateOnEnemySwarm && obs.VisibleEnemyCount >= 3) {
        return true;
    }
    
    // Learned termination (v10.0)
    if (term.bEnableLearnedTermination && rlLogit > term.LearnedThreshold) {
        return true;
    }
    
    return false;
}
```

```cpp
public:

    // 56 features: 52 base + 4 option context
    
    // Option context features:
    // - Strategy one-hot: [1,0,0,0] for Attack
    // - Time elapsed: normalized [0,1]

    // - Option urgency: (elapsed / expectedDuration)
    
    // ===== Network Heads =====
    
    /** Strategy-specific tactical parameters (v9.0) */
    TArray<float> TacticalParametersHead(const TArray<float>& features);
    // Output: [Aggression, Cover, Spread, Risk] ∈ [0,1]^4
    
    /** Termination decision head (v10.0 NEW) */
    float TerminationHead(const TArray<float>& features);
    // Output: logit ∈ [0,1], P(should_terminate | state)
    
    // ===== Training =====
    
    /** Compute termination reward */
    float TerminationReward(
        float currentValue,
        float bestAlternativeValue,
        bool terminationOccurred
    ) {
        // Positive reward if termination improved expected return
        float advantage = bestAlternativeValue - currentValue;
        
        if (terminationOccurred) {
            return advantage > 0 ? advantage : -abs(advantage);
        } else {
            return advantage < 0 ? abs(advantage) : -advantage;
        }
    }
};
```

### 3.6 Temporal MCTS Main Loop

```cpp
// File: AI/MCTS/TemporalMCTS.cpp

/**
 * v10.0: MCTS plans option sequences rather than single strategies
 */
class FTemporalMCTS {
public:
    // ===== Configuration =====
    
    int32 MaxIterations = 1000;
    int32 MaxDepth = 3;              // Option sequence depth
    float PlanningHorizon = 60.0f;   // seconds
    float ExplorationConstant = 1.41f;
    
    // ===== Core Algorithm =====
    
    TArray<FTacticalOption> PlanOptionSequence(const FGameState& initialState) {
        FTemporalMCTSNode* root = CreateRootNode(initialState);
        
        for (int32 iter = 0; iter < MaxIterations; ++iter) {
            // 1. Selection: Traverse tree using Temporal UCB1
            FTemporalMCTSNode* node = SelectNode(root, initialState.CurrentTime);
            
            // 2. Expansion: Add new option combinations
            if (ShouldExpand(node)) {
                node = ExpandNode(node);
            }
            
            // 3. Simulation: Rollout option sequence
            float reward = SimulateOptionSequence(node, initialState);
            
            // 4. Backpropagation: Update statistics with temporal decay
            BackpropagateReward(node, reward);
        }
        
        // Extract best sequence
        return ExtractBestSequence(root);
    }
    
private:
    // ===== Selection Phase =====
    
    FTemporalMCTSNode* SelectNode(FTemporalMCTSNode* root, float currentTime) {
        FTemporalMCTSNode* node = root;
        
        while (!node->IsLeaf() && node->IsFullyExpanded()) {
            node = SelectBestChild(node, currentTime);
        }
        
        return node;
    }
    
    // ===== Expansion Phase =====
    
    FTemporalMCTSNode* ExpandNode(FTemporalMCTSNode* node) {
        // Generate new option combination for 4 agents
        TArray<FTacticalOption> newOptions = GenerateOptionCombination(node);
        
        FTemporalMCTSNode* child = new FTemporalMCTSNode();
        child->OptionAssignments = newOptions;
        child->NodeDuration = CalculateNodeDuration(newOptions);
        child->ActivationTime = node->ActivationTime + node->NodeDuration;
        child->Parent = node;
        
        node->Children.Add(child);
        return child;
    }
    
    // ===== Simulation Phase =====
    
    float SimulateOptionSequence(FTemporalMCTSNode* leaf, const FGameState& state) {
        FGameState simState = state;
        FTemporalMCTSNode* node = leaf;
        float totalReward = 0.0f;
        float timeElapsed = 0.0f;
        
        // Rollout from leaf to horizon
        while (timeElapsed < PlanningHorizon && node->GetSequenceDepth() < MaxDepth) {
            // Simulate option execution
            float optionReward = SimulateOption(node->OptionAssignments, simState);
            totalReward += optionReward;
            
            // Advance simulation state
            timeElapsed += node->NodeDuration;
            simState = PredictFutureState(simState, node->OptionAssignments, node->NodeDuration);
            
            // If at leaf, use default policy for remaining time
            if (node->IsLeaf()) {
                node = CreateDefaultOption(simState);
            } else {
                node = SelectBestChild(node, state.CurrentTime + timeElapsed);
            }
        }
        
        return totalReward;
    }
    
    // ===== Backpropagation with Temporal Decay =====
    
    void BackpropagateReward(FTemporalMCTSNode* leaf, float reward) {
        FTemporalMCTSNode* node = leaf;
        float timeFromLeaf = 0.0f;
        float decayLambda = 0.05f;  // Decay rate
        
        while (node != nullptr) {
            // Temporal credit assignment
            float decayedReward = reward * exp(-decayLambda * timeFromLeaf);
            
            node->TotalReward += decayedReward;
            node->VisitCount++;
            
            timeFromLeaf += node->NodeDuration;
            node = node->Parent;
        }
    }
    
    // ===== Option Generation =====
    
    TArray<FTacticalOption> GenerateOptionCombination(FTemporalMCTSNode* parent) {
        TArray<FTacticalOption> options;
        
        // 8 standard option templates × 4 agents = 32 base combinations
        // Progressive widening: Add duration variants as visit count increases
        int32 numDurations = GetNumDurationVariants(parent->VisitCount);
        
        for (int32 agentIdx = 0; agentIdx < 4; ++agentIdx) {
            EStrategyType strategy = SelectStrategyForAgent(agentIdx, parent);
            AObjective* target = SelectTargetObjective(strategy, parent);
            float duration = SelectDuration(strategy, numDurations);
            
            FTacticalOption opt = TacticalOptions::CreateOption(strategy, target, duration);
            options.Add(opt);
        }
        
        return options;
    }
    
    int32 GetNumDurationVariants(int32 visitCount) {
        // Progressive widening in temporal dimension
        float alpha = 0.5f;
        float k = 2.0f;
        return FMath::FloorToInt(k * FMath::Pow(visitCount, alpha));
        // visitCount=1 → 2 durations, visitCount=100 → 20 durations
    }
};
```

```cpp
// File: AI/MCTS/TemporalOptimizations.cpp

/**
 * Option Caching: Reuse similar option combinations
 */
class FOptionCache {
    TMap<FString, FTacticalOption> Cache;
    
    FString GetCacheKey(EStrategyType strategy, AObjective* target, float duration) {
        return FString::Printf(TEXT("%d_%s_%.1f"), 
            (int32)strategy, 
            *target->GetName(), 
            duration);
    }
    
    FTacticalOption* GetOrCreate(EStrategyType strategy, AObjective* target, float duration) {
        FString key = GetCacheKey(strategy, target, duration);
        if (Cache.Contains(key)) {
            return &Cache[key];
        }
        
        FTacticalOption opt = TacticalOptions::CreateOption(strategy, target, duration);
        Cache.Add(key, opt);
        return &Cache[key];
    }
};

/**
 * Node Recycling: Reuse MCTS nodes across planning iterations
 */
class FNodePool {
    TArray<FTemporalMCTSNode*> FreeNodes;
    
    FTemporalMCTSNode* Allocate() {
        if (FreeNodes.Num() > 0) {
            FTemporalMCTSNode* node = FreeNodes.Pop();
            node->Reset();
            return node;
        }
        return new FTemporalMCTSNode();
    }
    
    void Release(FTemporalMCTSNode* node) {
        FreeNodes.Add(node);
    }
};

/**
 * Simulation Approximation: Fast state prediction
 */
FGameState PredictFutureState(
    const FGameState& current,
    const TArray<FTacticalOption>& options,
    float duration
) {
    // Lightweight state prediction (no full physics simulation)
    FGameState predicted = current;
    predicted.CurrentTime += duration;
    
    for (int32 i = 0; i < options.Num(); ++i) {
        const FTacticalOption& opt = options[i];
        FAgentState& agent = predicted.AgentStates[i];
        
        // Approximate position after duration
        FVector targetPos = opt.TargetObjective->GetActorLocation();
        float moveSpeed = GetStrategyMoveSpeed(opt.Strategy);
        FVector displacement = (targetPos - agent.Position).GetSafeNormal() * moveSpeed * duration;
        agent.Position += displacement;
        
        // Approximate health change (engagement probability)
        if (opt.Strategy == EStrategyType::Attack) {
            agent.Health -= 0.1f * duration;  // Assumes combat
        }
    }
    
    return predicted;
}
```

## 5. Academic Contributions

### 5.1 Novel Integration

**Problem:** Existing work separates hierarchical planning (MCTS) and continuous control (RL)

**Contribution:** Seamless integration via Options Framework
- MCTS operates on option space (discrete, temporally extended)
- RL operates on action space (continuous, instantaneous)
- Bidirectional communication through learned termination

**Related Work:**
- Hierarchical MCTS: Single-agent, discrete actions [argmin.lis.tu-berlin](https://argmin.lis.tu-berlin.de/papers/15-vien-AAAI.pdf)
- Continuous MCTS: No hierarchical structure [ijcai](https://www.ijcai.org/Proceedings/16/Papers/104.pdf)
- Options + RL: No MCTS planning [people.cs.umass](https://people.cs.umass.edu/~barto/courses/cs687/Sutton-Precup-Singh-AIJ99.pdf)

**CORTEX v10.0:** Multi-agent + Hierarchical + Continuous + Real-time

### 5.2 Learned Termination Conditions

**Key Innovation:** Data-driven answer to "When to replan?"

**Traditional Approaches:**
- Fixed intervals (v9.0: every 30s) → wasteful or delayed
- Hand-crafted triggers (HP < 20%) → brittle, domain-specific

**CORTEX v10.0 Approach:**
```
RL Network: obs → [tactical_params, termination_logit]

Reward:
  r_termination = {
    +advantage  if termination improved value
    -penalty    if termination degraded value
  }

Training:
  Policy learns: "Terminate when advantage(replan) > cost(replan)"
```

**Academic Significance:**
- Adaptive replanning frequency
- Generalizes across scenarios (capture, defend, retreat)
- Reduces computational overhead (30% fewer MCTS calls in stable situations)

### 5.3 Temporal UCB1 Algorithm

**Extension of UCB1 for time-aware planning**

**Standard UCB1:**
```
UCB(node) = exploitation + C * sqrt(log(N_parent) / N_node)
```

**Temporal UCB1 (v10.0):**
```
Temporal-UCB(node, t) = 
    exploitation 
    + C * exploration * exp(-λ * |t_node - t_current|)
    + urgency_bonus(t_node, t_current)

where:
  λ = temporal decay rate
  urgency_bonus = bonus for near-term decisions
```

**Properties:**
- Prioritizes near-term plans (exploitation of time)
- Gradually explores distant futures (temporal exploration)
- Balances planning horizon with decision urgency

**Research Contribution:** First application of temporal discounting in UCB1 for real-time games

### 5.4 Progressive Widening in Temporal Dimension

**Standard Progressive Widening:** Expands action space as visits increase

**CORTEX v10.0 Extension:** Expands duration space

```cpp
num_durations(visit_count) = k * visit_count^α

Initial (visit=1): Explore {10s, 30s, 60s}
Mid-training (visit=100): Explore {5s, 10s, 15s, ..., 60s}
Converged (visit=1000): Fine-grained {8s, 12s, 17s, 23s, ...}
```

**Benefits:**
- Early exploration focuses on coarse temporal decisions
- Refinement occurs as value estimates stabilize
- Avoids combinatorial explosion of duration × strategy × target

### 6.1 Research Questions
